DataSource

From Wikipedia, the free encyclopedia

DataSource
Type Software Pattern / Interface
Domain Data Management, Software Engineering
Common Implementations JDBC, ODBC, ADO.NET
Primary Role Abstraction layer for connection management

In computer science and data architecture, a DataSource (or data source) is a name given to the connection set up to a storage repository, such as a database, flat file, or cloud service. It encapsulates the underlying details required to establish access to the physical storage layer, providing a unified abstraction for application software.

Overview

A data source acts as a mediator between an application and the raw data payload. By isolating connection settings—such as host IP addresses, authentication credentials, schema configurations, and port definitions—from application logic, developers can alter backend infrastructure without modifying source code.

Implementations

Java Database Connectivity (JDBC)

In the Java Enterprise landscape, the javax.sql.DataSource interface serves as an alternative to the traditional DriverManager facility. Preferred for enterprise-grade applications, it supports key operational mechanisms such as connection pooling and distributed transactions.

Open Database Connectivity (ODBC)

In Microsoft Windows and Unix-like environments, a Data Source Name (DSN) serves as the standard identifier pointing to an ODBC driver and target database pair.
